# Smart Community Water Supply Problem Reporting and Repair Management System

Course: Object-Oriented Programming (CS 2010)
Group: 2

## Description
A Java desktop application where residents report water supply problems
(leaks, no water, low pressure). The system ranks problems by urgency,
assigns repair workers, and tracks repair progress.
